M8 Web Hub 1.0

Publicação na Vercel:
1. Extraia este ZIP.
2. Crie um repositório no GitHub e envie os arquivos da pasta m8-web-hub para a raiz.
3. Na Vercel, escolha Add New > Project, importe o repositório.
4. Framework Preset: Other. Build Command: deixe vazio. Output Directory: deixe vazio.
5. Publique e abra o endereço HTTPS no tablet, se autorizado.

A página executa apenas diagnósticos locais do navegador. Não contorna bloqueios administrativos.
